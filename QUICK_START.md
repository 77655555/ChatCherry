# 🚀 Быстрый старт Gravity Hopper

## Установка и запуск за 3 шага:

### 1️⃣ Установите Pygame

```bash
pip install pygame
```

или

```bash
pip3 install pygame
```

### 2️⃣ Запустите игру

```bash
python gravity_hopper.py
```

или

```bash
python3 gravity_hopper.py
```

### 3️⃣ Играйте!

Откроется окно 360×640 пикселей с игрой.

## 🎮 Краткое руководство

### Управление:
- **Клик мышью** = прыжок
- **Короткий клик** = короткий прыжок
- **Долгий клик (удерживайте >300мс)** = высокий прыжок  
- **Свайп (перетащите мышь влево/вправо)** = движение в воздухе

### Платформы:
- 🟢 **Зеленые** - обычные, безопасные
- 🔵 **Синие** - движутся влево-вправо
- 🟠 **Оранжевые** - хрупкие, исчезают после касания
- 🟡 **Желтые** - ускорители (пружины)

### Собираемое:
- 💎 **Кристаллы** - +10 очков
- ⭐ **Бонусы** - множитель ×2 на 10 секунд
- 🛡️ **Щиты** - спасают от одного падения

### Цель:
Подниматься как можно выше и собирать кристаллы!

## 🔧 Устранение неполадок

### Pygame не установлен?
```bash
pip install --upgrade pip
pip install pygame>=2.5.0
```

### Используете виртуальное окружение?
```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте его
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите pygame
pip install pygame

# Запустите игру
python gravity_hopper.py
```

### Ошибка "No module named 'pygame'"?
Убедитесь, что вы установили pygame и используете правильную версию Python:
```bash
python3 --version
pip3 install pygame
python3 gravity_hopper.py
```
