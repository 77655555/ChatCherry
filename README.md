# Gravity Hopper - Мобильная 2D Игра

Увлекательная мобильная 2D игра с простым управлением, оптимизированная для сенсорного экрана.

## Описание

**Gravity Hopper** - это аркадная игра с физикой, где игрок управляет шариком-антигравитационным роботом, который должен подниматься как можно выше через систему движущихся платформ в футуристическом мире.

## Особенности игры

### Геймплей
- **Цель**: Подниматься как можно выше, перепрыгивая с платформы на платформу
- **Сбор предметов**: Собирайте энергетические кристаллы для увеличения счета
- **Выживание**: Избегайте падения за нижнюю границу экрана

### Управление
- **Короткое нажатие/клик**: Короткий прыжок
- **Долгое нажатие/удержание**: Высокий прыжок (сила зависит от времени удержания)
- **Свайп влево/вправо**: Небольшое смещение в воздухе для коррекции траектории
- **Клавиши-стрелки**: Альтернативное управление движением
- **Пробел**: Прыжок
- **P**: Пауза

### Типы платформ
1. **Обычные платформы** (зеленые) - статичные, безопасные
2. **Движущиеся платформы** (синие) - двигаются горизонтально
3. **Хрупкие платформы** (оранжевые) - исчезают через 0.5 секунды после касания
4. **Ускорители** (желтые) - пружины, увеличивают высоту прыжка в 1.5 раза

### Собираемые предметы
- **Энергетические кристаллы** (фиолетовые) - +10 очков
- **Временные бонусы** (желтые с "x2") - удваивают очки на 10 секунд
- **Щиты** (золотые) - защита от одного падения

### Визуальные эффекты
- Анимация прыжка с эффектом частиц
- Плавное перемещение камеры за игроком
- Параллакс-фон с тремя слоями звезд
- Эффекты свечения и анимации

## Технические характеристики

- **Язык**: Python 3.7+
- **Библиотека**: Pygame 2.5.2
- **Разрешение**: 360×640 пикселей (портретная ориентация)
- **FPS**: 60 кадров в секунду
- **Управление**: Адаптировано под мобильные устройства (симуляция мышью)

## Установка и запуск

### Требования
- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Установка
1. Клонируйте репозиторий или скачайте файлы игры
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

### Запуск игры
```bash
python main.py
```

## Игровые классы

### Основные компоненты
- **`GravityHopper`** - Главный класс игры, управляет игровым циклом
- **`Player`** - Класс игрока с физикой и анимацией
- **`Platform`** - Различные типы платформ с уникальным поведением
- **`Collectible`** - Собираемые предметы (кристаллы, бонусы, щиты)
- **`Camera`** - Система камеры с плавным следованием
- **`ParallaxBackground`** - Многослойный параллакс-фон
- **`GameUI`** - Пользовательский интерфейс и система очков
- **`TouchControls`** - Система управления для мобильных устройств
- **`Particle`** - Система частиц для визуальных эффектов

### Генераторы
- **`PlatformGenerator`** - Процедурная генерация платформ
- **`CollectibleGenerator`** - Генерация собираемых предметов

## Физика игры

- **Гравитация**: Реалистичная физика падения
- **Прыжки**: Переменная сила прыжка в зависимости от времени нажатия
- **Сопротивление воздуха**: Постепенное замедление горизонтального движения
- **Коллизии**: Точная система коллизий с платформами
- **Упругость**: Различные типы отскоков от платформ

## Система прогресса

- **Очки**: Начисляются за сбор кристаллов и достижение высоты
- **Множители**: Временные бонусы удваивают получаемые очки
- **Рекорды**: Автоматическое сохранение лучшего результата
- **Статистика**: Отслеживание высоты, собранных кристаллов и общих очков

## Адаптация под мобильные устройства

Хотя игра написана на Python/Pygame, она полностью адаптирована под мобильное управление:

- **Сенсорное управление**: Симулируется через мышь для тестирования
- **Портретная ориентация**: Оптимизировано для вертикального экрана
- **Простые жесты**: Тап, долгое нажатие, свайпы
- **Визуальная обратная связь**: Индикатор зарядки прыжка
- **Мобильный UI**: Крупные элементы интерфейса

## Советы по игре

1. **Изучите типы платформ** - каждый тип требует своей стратегии
2. **Используйте долгие прыжки** - для преодоления больших расстояний
3. **Собирайте кристаллы** - они дают очки и улучшают результат
4. **Активируйте множители** - удваивайте очки в нужный момент
5. **Берегите щиты** - они спасают от падения
6. **Планируйте траекторию** - используйте свайпы для коррекции полета
