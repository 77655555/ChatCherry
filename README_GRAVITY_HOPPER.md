# Gravity Hopper 🎮

Увлекательная мобильная 2D игра-аркада с физикой, созданная на Python с использованием Pygame.

## 🎯 Описание

Gravity Hopper - это динамичный платформер, где вы управляете антигравитационным роботом-шариком, который должен подниматься как можно выше через систему движущихся платформ в футуристическом мире.

## ✨ Особенности

### Геймплей
- **Реалистичная физика** с гравитацией и инерцией
- **Процедурная генерация** бесконечных уровней
- **Система очков** с множителями и бонусами
- **Плавная камера**, следующая за игроком
- **Параллакс-фон** с тремя слоями для глубины

### Типы платформ
1. **Обычные платформы** (60%) - зеленые, статичные
2. **Движущиеся платформы** (25%) - синие, двигаются горизонтально
3. **Хрупкие платформы** (15%) - оранжевые, исчезают после касания
4. **Ускорители** (редкие) - желтые пружины, увеличивают высоту прыжка в 1.5 раза

### Собираемые предметы
- **Энергетические кристаллы** 💎 - дают +10 очков
- **Временные бонусы** ⭐ - множитель ×2 на 10 секунд
- **Щиты** 🛡️ - защита от одного падения

### Эффекты
- **Анимация свечения** игрока
- **Система частиц** для прыжков и сбора предметов
- **Плавные анимации** платформ и собираемых предметов
- **Футуристический визуальный стиль**

## 🎮 Управление

Игра оптимизирована для сенсорных экранов, но адаптирована для тестирования с мышью:

- **Короткий клик** - короткий прыжок
- **Долгое удержание** (>300мс) - высокий прыжок
- **Свайп влево/вправо** - горизонтальное движение в воздухе

## 🚀 Установка и запуск

### Требования
- Python 3.7 или выше
- Pygame 2.5.0 или выше

### Установка зависимостей

```bash
pip install pygame
```

Или используйте файл requirements.txt:

```bash
pip install -r requirements.txt
```

### Запуск игры

```bash
python gravity_hopper.py
```

## 📱 Технические характеристики

- **Разрешение**: 360×640 пикселей (портретная ориентация)
- **FPS**: 60 кадров в секунду
- **Язык**: Python 3
- **Библиотека**: Pygame

- Избегать падения за нижнюю границу экрана

## 🏆 Система прогресса

Игра отслеживает:
- **Текущий счет** - очки за собранные кристаллы
- **Лучший результат** - максимальный счет за все сессии
- **Текущая высота** - в метрах
- **Количество собранных кристаллов**
- **Текущий множитель** - отображается с таймером

## 🎨 Цветовая схема

- **Игрок**: Голубой (Cyan) с белым ядром и свечением
- **Обычные платформы**: Зеленый
- **Движущиеся платформы**: Синий
- **Хрупкие платформы**: Оранжевый
- **Ускорители**: Желтый
- **Кристаллы**: Голубой (Cyan)
- **Бонусы**: Желтый
- **Щиты**: Фиолетовый
- **Фон**: Темно-синий с мерцающими звездами

## 🔧 Настройка сложности

В коде игры можно настроить различные параметры:

```python
# Физика
GRAVITY = 0.5  # Сила гравитации
JUMP_FORCE_SHORT = -12  # Сила короткого прыжка
JUMP_FORCE_LONG = -18  # Сила длинного прыжка

# Генерация платформ
# В функции generate_platform() можно изменить вероятности типов платформ
```

## 📝 Структура кода

- **Game** - основной класс игры, управляет всеми компонентами
- **Player** - класс игрока с физикой и коллизиями
- **Platform** - класс платформ с различными типами
- **Collectible** - собираемые предметы
- **Particle** - система частиц для эффектов
- **Camera** - плавная камера, следящая за игроком
- **ParallaxBackground** - многослойный параллакс-фон
- **GameState** - перечисление состояний игры (меню, игра, окончание)

## 🐛 Известные особенности

- Игра оптимизирована для вертикальной ориентации 360×640
- Для запуска на реальном мобильном устройстве потребуется дополнительная настройка с использованием Pygame Subset for Android (Pygame4Android) или Kivy

## 💡 Советы по игре

1. Используйте короткие прыжки для точного приземления
2. Сохраняйте длинные прыжки для больших расстояний
3. Собирайте множители для увеличения счета
4. Берегите щиты для критических моментов
5. Остерегайтесь хрупких платформ (оранжевых)
6. Используйте ускорители (желтые) для быстрого подъема
